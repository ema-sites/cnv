# carousel-hero

Custom **carousel** block. Purpose: full-width homepage image slideshow with dot navigation, auto-advancing.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: image cell | optional content cell (heading/text/link; a link alone makes the whole image clickable).
