# breadcrumb

Custom **custom** block. Purpose: breadcrumb trail (Home > section > current page) shown at the top of content pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell holding a list of links ending with the current page name (plain text); an empty block derives the trail from the URL path.

## Supported variations

No variations.
