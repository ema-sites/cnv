# services

Homepage "What do you need today?" router: a grid of labelled service tiles, with an optional search
field. Each tile is one link (icon, label and an optional second line such as the system name).

## Authoring (Document Authoring)

Put the section heading, a one-line intro and an "All online services" link above the table as normal
text in the same section. The search field (if any) is placed with that text.

| Services | | |
|---|---|---|
| search | Search for a service or topic | /search |
| :property-tax: [Pay property taxes](/home-property/property-taxes) | | |
| :report-issue: [Report an issue](/city-hall/online-services/cityfix) | CityFix | |

- **search row** (optional): the word `search`, the placeholder text, and the search page.
- **tile rows**: an icon (`:name:` from `/icons/`), the link, and an optional second line.

Icons available: `property-tax`, `utility-bill`, `report-issue`, `collection`, `permit`, `property-map`.

## Supported variations

No variations.
