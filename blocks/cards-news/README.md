# cards-news

Custom **cards** block. Purpose: homepage City News & Events list: linked headline, one-line summary and READ MORE link per story.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per story: linked title (or heading) | summary | optional READ MORE link (cells may be merged into one); READ MORE defaults to the title link.
