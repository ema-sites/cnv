# carousel-gallery

Custom **carousel** block. Purpose: one photo gallery (the source's Galleria theme): 370px slideshow stage with cross-fade and prev/next, a bar with thumbnail-grid toggle, play/pause, popout lightbox, n / total counter + caption and fullscreen toggle; the thumbnail grid overlays the stage when toggled.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per photo: image cell | optional caption cell (falls back to the image alt text).

## Supported variations

The option classes name the catalogued parts of the one gallery; every instance renders the same full gallery.

| Variation | Option class |
| --- | --- |
| Thumbnails | `thumbnails` |
| Light | `light` |
| Dark Grey | `dark-grey` |
