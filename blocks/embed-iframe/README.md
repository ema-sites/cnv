# embed-iframe

Custom **embed** block. Purpose: embedded external page in an iframe (council video player, interactive map, Trumba events calendar).

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): first row: link to embed; optional key/value rows: height (px) or aspect (e.g. 16/9), title. Trumba calendar links (trumba.com/calendars/<web-name>) load the Trumba script.

## Supported variations

No variations.
