# council-video-picker

Custom **custom** block. Purpose: Select a date dropdown that loads the chosen council meeting video into a player.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per meeting: date label | video link; optional first single-cell row sets the visible field label (default "Select a Date"; rendered with a trailing colon). The dropdown placeholder is always "Select a date ...".

## Supported variations

No variations.
