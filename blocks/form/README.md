# form

Custom **custom** block. Purpose: one web form (feedback, subscription): text fields, comment textarea, checkboxes and a Submit button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per field: Label (trailing * = required) | type (text, email, tel, number, date, textarea, checkbox, checkboxes, radio, select, hidden, submit) | options or placeholder; settings rows: action | submit URL, method | POST/GET, thank you | message; single-cell rows are intro text.
