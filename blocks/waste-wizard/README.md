# waste-wizard

Custom **embed** block. Purpose: embeds the third-party ReCollect What Goes Where recycling lookup / collection calendar widget (vendor script).

## Authoring (Document Authoring)

Key/value rows (label in the first cell, value in the second): optional key/value rows: area | CityNorthVancouver, name | wizard or calendar, page | tabbed_widget, service | waste, script | vendor script URL.
