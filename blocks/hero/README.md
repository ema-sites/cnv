# hero

One full-width photograph with the page heading as real text on a navy scrim, and an optional
featured call-out (a campaign or deadline). Replaces the old rotating banner: no text inside images,
no autoplay.

## Authoring (Document Authoring)

| Hero | |
|---|---|
| photo | **Heading 1** and a one-line intro |
| **Heading 2** for the call-out, one line, and a **bold link** (shown as a button) | |

- Row 1: the photo (decorative, leave alt text empty) and the h1 + intro.
- Row 2 (optional): the call-out. On phones it moves below the next section so the services stay in
  the first screen.

## Supported variations

No variations.
