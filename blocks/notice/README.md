# notice

Custom **custom** block. Purpose: bordered callout with an icon and a status message, optional heading and Learn more link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: icon cell (:icon:, image or icon name; empty = alert icon) | content cell (optional heading, text, optional link).

Named icons are drawn as inline SVG (no icon font): `alert` (default), `info`, `file-check`, `file`, `pencil`/`edit`, `seedling`, `calendar`, `clock`. Unknown names fall back to `alert`. The icon is 40px and uses the brand blue (#438ece).

## Supported variations

- `orange`: orange icon.
- `green`: forest green icon.
