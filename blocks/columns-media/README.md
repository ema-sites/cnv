# columns-media

Custom **columns** block. Purpose: two columns: heading, text or bullet list beside a large photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: text cell | image cell (either order); with image-left-boxed-text the image shows on the left and the text sits in a coloured panel.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Left Boxed Text | `image-left-boxed-text` |
